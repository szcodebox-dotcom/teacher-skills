# 语言能力支持

很多"听不懂要求"不是态度问题，是语言通道的问题。这个 skill 做三件事：简化表达、调整作业、安排同伴协作。**不代替言语治疗等专业诊断。**

## 何时触发

老师说"他总听不懂要求""表达不清楚""题目读不懂"时触发。

## 输入清单

1. 具体困难点（听指令 / 口头表达 / 读题理解 / 书面表达，可多选）；
2. 学科与年级（语言要求不同）；
3. 已有支持措施及效果。

## 工作流程

1. **简化任务表达**：
   - 短句化：一次只给一个指令；
   - 分步呈现：步骤编号 + 视觉辅助（图示、示例）；
   - 检查理解：让学生用自己的话复述要求（不是"听懂了吗"）。
2. **作业调整**：
   - 读题辅助：关键词标色、分段读题；
   - 答题方式替代：口头作答、画图作答同样给分；
   - 题量与呈现：大字、宽行距、留白。
3. **同伴协作**：安排固定语伴，角色分工明确（如一人读题一人记录），定期轮换。
4. **进步记录**：每周 1 条可观察的进步（如"能复述两步指令"）。

## 输出规范

- 课堂调整清单（一页纸：场景 / 调整动作）；
- 作业调整方案；
- 简化表达示例（改前 vs 改后各 3 组）。

## 边界（硬性）

- 区分语言困难与态度问题，不批评"不用心"；
- **学生支持不代替专业诊断**；怀疑构音/听力等生理问题建议转介检查；
- **结果由教师核对后使用**。
