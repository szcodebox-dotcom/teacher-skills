# 安全教育通知

安全通知最怕两种毛病：只有口号没有动作，风险列了但家长不知道干什么。写法：场景化风险 + 家长具体动作 + 学生自查。

## 何时触发

老师说"写个假期安全通知""防溺水通知""安全教育告家长书"时触发。

## 输入清单

1. 时段（假期起止）与风险主题（防溺水 / 交通 / 消防 / 网络 / 其他，可多选）；
2. 学校有无统一模板或必含条款（有就先套用）；
3. 回执要求。

## 工作流程

1. **风险清单**：按场景列（居家 / 出行 / 水域 / 网络），每条一句话说清"防什么"。
2. **家长配合事项**：写具体动作，不写口号。对比：不说"加强监护"，说"每天确认孩子去向，晚归先电话联系"。
3. **学生自查小贴士**：3–5 条，孩子能自己照着做的。
4. **规范收尾**：假期值班/紧急联系方式占位符（老师填），附家长签收回执。

## 输出规范

- 通知正文（可直接发）+ 签收回执；
- 语气严谨规范，不煽情不堆砌口号；关键日期加粗。

## 边界

- 表述以学校口径为准，有模板先套模板；**由教师核对后发送**。
- 不编造事故案例吓唬人。
