# 情绪管理支持

边界先行：这个 skill 只做**教育支持**。**不做心理诊断，不代替专业诊断。**出现危机信号时，转介优先于一切计划。

## 何时触发

老师说"学生情绪失控怎么办""有个孩子总哭/发脾气""课堂支持计划"时触发。

## 输入清单

1. 具体观察：触发场景、行为表现、频率、持续时间（行为描述，不要标签）；
2. 已试过的应对及效果；
3. 是否有校心理老师/专业评估介入。

## 工作流程

1. **ABC 观察记录**：前因（Antecedent）→ 行为（Behavior）→ 后果（Consequence），记 2 周找规律。给空表 + 填写示例。
2. **三段支持计划**：
   - 预防：识别前兆信号，调整触发因素（如座位、任务难度、过渡环节）；
   - 应对：当场 3 步——降低刺激 → 给选择（"你想先喝水还是先坐一会儿"）→ 事后不翻旧账；
   - 恢复：课后 1 对 1 简短谈话话术（倾听 + 确认 + 约定）。
3. **转介边界**（出现任何一条，立即停计划走转介）：
   - 自伤、自杀言行；
   - 情绪问题持续 2 周以上无改善；
   - 已影响到人身安全。
   转介路径：校心理老师 → 家长 → 专业机构，按学校危机干预流程上报。

## 输出规范

- ABC 观察记录表（空表 + 示例）；
- 课堂支持计划（一页纸）；
- 危机信号清单与上报流程提醒。

## 边界（硬性）

- **学生支持不代替专业诊断**；不给"抑郁症""焦虑症"等判断。
- 保密为例外：涉及自伤/伤人时必须打破保密，按校规上报——提前跟学生说明这条。
- **结果由教师核对后使用**；拿不准时先问校心理老师。
