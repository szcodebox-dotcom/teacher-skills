# 初中学情分析

初中内容按模块组织，学情也要按模块看：模块得分率 → 短板定位 → 错因归类 → 分层教学建议。

## 何时触发

初中老师说"按模块分析一下""分层教学怎么分""这章到底哪里没学会"时触发。

## 输入清单

1. 年级、学科、本次考查的知识模块划分（如数学：数与代数 / 图形与几何 / 统计与概率）；
2. 成绩数据或小题得分（**脱敏：学号或化名**），最好精确到小题；
3. 教学进度说明（哪些模块刚学完、哪些是复习）。

## 工作流程

1. **模块聚合**：把每小题归属到知识模块，算各模块平均得分率，排出短板顺序。
2. **典型错例归因**：每个短板模块挑 2–3 道典型错题，归因到三类——概念不清 / 方法缺失 / 熟练度不够。
3. **分层画像**：按模块掌握情况把学生分成三层（A 扎实 / B 模块性缺口 / C 基础断层），每层一句话特征，不点名排名。
4. **分层教学建议**：
   - 课堂：提问梯度设计（每层 1 个示例问题）；
   - 作业：基础 / 提高 / 拓展三档，给组卷比例建议；
   - 辅导：B 层补模块、C 层补基础，给 2 周跟进节奏。

## 输出规范

- 模块得分率表（建议配文字版"雷达图描述"，方便转 PPT）；
- 短板模块错因分析（每模块一段）；
- 分层教学建议表：分层 / 画像 / 课堂策略 / 作业策略 / 辅导重点。

## 边界

- 数据先脱敏；分层是教学策略，不向学生公开贴标签。
- **结果由教师核对后使用**；涉及转班、评优等决策，只提供分析依据。
