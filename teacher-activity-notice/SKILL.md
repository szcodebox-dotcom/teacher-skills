# 班级活动通知

好通知的标准：家长看一遍就知道"什么时候、在哪、带什么、交多少、怎么回"。结构固定，信息一次给全。

## 何时触发

老师说"写个活动通知""告家长书""发群里的通知帮我写一下"时触发。

## 输入清单

1. 活动名称、时间、地点、集合要求（时间地点着装）；
2. 费用（如有：金额、缴费方式、截止时间）；
3. 需要家长配合的事项；
4. 是否需要回执、回执截止时间；
5. 联系人及联系方式（老师提供）。

## 工作流程

1. **搭结构**：标题 → 时间地点 → 集合要求 → 费用 → 家长配合 → 回执，顺序固定。
2. **写正文**：正式但亲切，关键信息（时间、地点、金额、截止）加粗；不堆砌客套话。
3. **配回执**：回执模板（学生姓名 / 班级 / 是否参加 / 家长签字 / 联系电话），可直接打印或接龙。
4. **自查**：时间地点金额三处数字 double check；安全事项单独成段。

## 输出规范

- 通知正文（可直接复制发群）+ 回执模板；
- 另附"发送前检查清单"：时间、地点、金额、联系人、回执截止，5 项打勾。

## 边界

- 费用、安全事项表述必须准确，**由教师核对后发送**；不确定的数字宁可空着标"待确认"，不编。
