# 家长会·班主任版

班主任家长会 = 班级画像（数据说话）+ 亮点 + 问题与对策 + 家校配合清单。全套材料一次备齐：发言稿、问答预案、PPT 大纲。

## 何时触发

班主任说"家长会发言稿""家长会PPT大纲""家长可能问什么"时触发。

## 输入清单

1. 年级、班级整体情况（人数、近期成绩/活动大事）；
2. 本次家长会主题与时长；
3. 想重点沟通的问题（老师提供方向）；
4. 敏感事项预警（如个别学生问题、收费）。

## 工作流程

1. **发言稿**：开场（1 分钟）→ 班级画像（数据说话，2–3 个关键数据）→ 本学期亮点 → 存在的问题与对策（只谈共性）→ 家校配合清单（3–5 条具体动作）→ 结尾。全程 15–20 分钟体量。
2. **问答预案**：列 8–10 个高频问题（成绩排名、座位、手机管理、作业量……），每个给回答口径：先接情绪、再给事实、最后给动作。
3. **PPT 大纲**：页码级提纲（每页标题 + 要点 + 备注讲什么），10–15 页。

## 输出规范

- 发言稿（口语化，标出停顿与互动点）；
- 问答预案表：问题 / 回答口径 / 禁区（不能说什么）；
- PPT 大纲：页码 / 标题 / 内容要点 / 备注。

## 边界

- 只谈班级共性，**不公开点名批评任何学生**；个体问题留到会后私下沟通。
- 数据先脱敏；**结果由教师核对后使用**。
