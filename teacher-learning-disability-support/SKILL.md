# 学习障碍支持

边界先行："学习障碍"是医学/心理学诊断，老师不下这个结论。这个 skill 做的是**教育侧的三件事**：课堂作业调整、阶段辅导方案、转介专业评估。**不代替专业诊断。**

## 何时触发

老师说"各科都跟不上怎么办""疑似学习障碍""阶段辅导方案"时触发。

## 输入清单

1. 各科具体表现（哪科学、哪类任务卡住，行为描述）；
2. 已尝试的干预及持续时间、效果；
3. 家长沟通情况、是否有专业评估。

## 工作流程

1. **课堂与作业调整清单**：
   - 课堂：任务分解、延长作答时间、多感官输入（看+听+动手）；
   - 作业：量减质保、允许辅助工具、分解截止点；
   - 评价：看进步幅度，不只看绝对分数。
2. **阶段辅导方案**：一阶段 4–6 周，每阶段定 1 个小目标（如"两位数乘法计算正确率到 80%"），设 2 个评估点，到点复盘调计划。
3. **转介建议**：如调整 6–8 周仍无改善，或家长主动问——给转介话术（"建议做一次专业评估，是为了更精准地帮他，不是贴标签"）+ 本地可转介渠道占位（老师填）。
4. **长期跟踪表**：日期 / 干预 / 表现 / 下一步。

## 输出规范

- 调整清单（一页纸）；
- 阶段辅导方案表：阶段 / 目标 / 干预 / 评估点 / 复盘时间；
- 转介沟通话术（200 字）。

## 边界（硬性）

- **绝不由老师下"学习障碍"诊断**；必须建议走专业评估。
- 不拿学生跟他人比较；保护隐私，方案不公开。
- **结果由教师核对后使用**；涉及资源教室/送教等走学校流程。
