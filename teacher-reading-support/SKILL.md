# 阅读困难支持

阅读困难 ≠ 不爱读书。先拆任务、给支架，再谈量。这个 skill：拆分阅读任务、提供关键词与支架、调整作业。**不代替阅读障碍的专业诊断。**

## 何时触发

老师说"读书很慢""读不懂题""朗读困难"时触发。

## 输入清单

1. 具体表现（速度慢 / 理解差 / 朗读卡顿 / 逃避阅读，可多选）；
2. 年级、学科场景（语文阅读 / 数学读题 / 英语）；
3. 已试过的方法。

## 工作流程

1. **拆分阅读任务**：预读（看标题插图猜内容）→ 分段读（一次一段）→ 关键词（每段圈 1–2 个）→ 复述（用自己的话讲一遍）。四步做成书签卡，贴桌上。
2. **支架工具**：
   - 关键词表：课前给 5–8 个关键词注音释义；
   - 思维导图模板：填空式（谁 / 在哪 / 干什么 / 结果）；
   - 指读/跟读：允许初期用，不批评。
3. **作业调整**：阅读量分层、长文配音频、评价看理解不看速度。
4. **兴趣保护**：每天 10 分钟自由阅读（自选书），只记录不考核。

## 输出规范

- 阅读支持方案（一页纸）；
- 四步阅读书签卡（可直接打印）；
- 思维导图填空模板（文字版）。

## 边界（硬性）

- **学生支持不代替专业诊断**；持续困难建议专业评估（如阅读障碍筛查）；
- 不当众让其朗读出丑；保护阅读兴趣优先于纠正速度；
- **结果由教师核对后使用**。
