# 班级活动方案

一个活动方案 = 一句话目标 + 分时段流程 + 物料清单 + 安全预案。缺了预案的不叫方案。

## 何时触发

老师说"帮我做个班会方案""研学活动怎么做""班级活动策划一下"时触发。

## 输入清单

1. 活动类型（班会 / 研学 / 节日活动 / 其他）；
2. 年级、人数、时间、地点；
3. 活动目标（一句话，老师自己定，我帮着打磨）；
4. 特殊约束（预算、校外审批、家长参与与否）。

## 工作流程

1. **定目标**：把老师的想法压成一句话目标 + 2–3 条可观察的成功标准。
2. **拆流程**：按时间轴拆环节，每个环节写清：时间 / 内容 / 负责人 / 产出。
3. **物料清单**：分物资、人员、场地三类列出，标出"需提前准备"项与截止时间。
4. **安全预案**：列风险点（交通 / 天气 / 健康 / 走失等）× 每个风险点的应对动作和责任人。校外活动先提醒确认学校审批流程。
5. **任务分工**：简化版分工表（事项 / 负责人 / 完成时间）。

## 输出规范

- 方案文档（Markdown）：标题、目标、时间轴流程表、任务分工表、物料清单、安全预案表；
- 语言直接可用，不写空话口号；时间精确到分钟级（如班会）或半天级（如研学）。

## 边界

- 安全预案是必备项，不能省略；涉及校外、收费的，先提醒走审批。
- **结果由教师核对后使用**，尤其是时间、人数、责任人信息。
