# 小学学情分析

把一次考试或练习，变成一份能直接用的学情简报：整体画像 → 易错题定位 → 薄弱点归因 → 讲评与练习建议。

## 何时触发

小学老师说"分析一下这次成绩""找找易错题""看看班级薄弱点在哪"时触发。输入可以是成绩表截图、Excel、文字粘贴，或口述数据。

## 输入清单

先收齐这四样再动手，缺的直接问：
1. 年级、学科、考试/练习范围；
2. 成绩数据（**先脱敏：用学号或化名，不出现学生真实姓名**）；
3. 试卷结构（题型分值、满分）；
4. 特殊说明（缺考、题目争议）。

## 工作流程

1. **核口径**：确认满分、实考人数、缺考处理方式，口径不清先问，不硬算。
2. **整体画像**：平均分、优秀率、及格率、分数段人数分布，一句话定调（如"两头大、中间小"）。
3. **易错题定位**：按小题算得分率，得分率低于 60% 的标为易错题，附原题与错误集中点。
4. **薄弱点归因**：区分三类——知识没掌握 / 方法不到位 / 习惯性失分（审题、计算、书写）。
5. **个体关注**：进步明显、退步明显、持续波动三类学生各点 2–3 名（脱敏代号），给一句跟进建议。
6. **讲评建议**：按"先共性后个性、先易错后拓展"排出讲评顺序，标出每题建议用时。

## 输出规范

- 一页学情简报（Markdown 表格为主）：整体数据表 + 分数段分布 + 易错题表（含得分率与归因）；
- 讲评课重点清单：按顺序列出必讲题目与一句话讲评要点；
- 分层练习建议：基础巩固 / 提高拓展两组，各 3–5 道（可出题目标，不直接出整套卷）。

## 边界

- 数据必须先脱敏；不建议公开排名，尤其不点名后几名。
- 结论是"分析建议"，**结果由教师核对后使用**；不给学生贴标签式定性。
