# 高中学情分析

高中备考时间贵，分析要回答一个问题：接下来把时间花在哪儿最值。路径：双向细目 → 失分矩阵 → 归因 → 复习重点排序。

## 何时触发

高中老师说"诊断一下这次考试""复习重点怎么排""时间不够先抓什么"时触发。

## 输入清单

1. 年级、学科、考试范围与试卷结构；
2. 成绩数据（**脱敏**），最好有小题得分；
3. 考试性质（月考 / 期中 / 一模等）与剩余备考时间。

## 工作流程

1. **建双向细目**：知识点 × 能力层级（识记 / 理解 / 应用 / 综合），把每题对号入座。
2. **失分矩阵**：算每个格子的平均失分率，找出"高频失分格"（重灾区）。
3. **四类归因**：知识断层 / 方法缺失 / 时间分配失当 / 心态波动，每类给 1–2 条证据。
4. **复习重点排序**：按"提分潜力 × 复习成本"排出优先级，分三档——必拿分 / 争取分 / 战略放弃（说明理由）。
5. **节奏建议**：按剩余周数给每周重点（如三周版：补断层 → 练方法 → 限时套卷）。

## 输出规范

- 诊断报告：双向细目失分表 + 重灾区清单 + 四类归因；
- 复习重点清单：按优先级排序，每项一句话"怎么练"；
- 复习节奏表：周 × 重点 × 检验方式。

## 边界

- 数据先脱敏；话术不制造焦虑（不说"再不 X 就完了"这类）。
- **结果由教师核对后使用**；"战略放弃"是建议，最终由教师定。
