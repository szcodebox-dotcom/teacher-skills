# 课题申报书

申报书的评审逻辑：选题值不值得做 → 目标清不清晰 → 计划可不可行 → 成果够不够。按这个顺序帮老师把想法整理成规范文本。

## 何时触发

老师说"帮我写课题申报书""课题选题怎么定""立项申请书"时触发。

## 输入清单

1. 申报级别（区级 / 市级 / 省级 / 校级）与申报书模板（有模板先套模板）；
2. 研究方向或初步想法（一句话也行）；
3. 已有基础（做过 related 的课例、论文、数据）；
4. 团队成员与分工意向。

## 工作流程

1. **选题打磨**：把想法压成规范题目。公式：研究对象 + 核心问题 + 方法/载体。给 2–3 个备选并说明各自利弊。
2. **立项依据**：问题提出（教学真问题，有数据或案例支撑）→ 研究价值（一句话）。
3. **研究目标与内容**：目标 3 条（可测量）；内容分 3–4 块，每块对应目标。
4. **研究计划**：分阶段（准备 / 实施 / 总结）× 每阶段任务 × 时间节点 × 阶段成果。
5. **预期成果**：论文、课例、资源包、学生成长数据，列清单并标完成标准。
6. **填写说明**：对模板中每个栏位给一句话填写提示和常见坑。

## 输出规范

- 申报书正文框架（按模板章节，全文起草）；
- 选题备选与利弊分析；
- 自查清单：评审视角的 10 个问题（创新性够吗？工作量 realistic 吗？……）。

## 边界

- 概念表述规范，不堆大词；**可行性优先于创新噱头**，如实写团队基础。
- **结果由教师核对后使用**；涉及签字盖章的以学校科研处口径为准。
