# 注意力不足支持

先说清楚边界：这个 skill 只做**教育支持**——观察记录、任务拆分、作业调整、家校沟通。**不下任何诊断结论，不代替专业诊断。**

## 何时触发

老师说"有个学生注意力不集中怎么办""课堂上坐不住怎么支持"时触发。注意：触发词是具体困扰，不是标签。

## 输入清单

1. 具体观察（什么场景、什么行为、持续多久、频率）——**要行为描述，不要标签**（如"数学课 20 分钟后开始转笔、看窗外"）；
2. 已试过的方法及效果；
3. 家长是否提过相关情况 / 是否有专业评估（有则先问结论）。

## 工作流程

1. **整理观察记录**：时间 / 场景 / 具体行为 / 持续时长 / 可能的触发因素，做成记录表。先记两周再下判断。
2. **拆分课堂任务**：大任务拆成小步骤，每步配检查点（如"先读题→圈关键词→列式→检查"，每步举手示意）。
3. **座位与环境**：给 2–3 条可操作的调整建议（靠前、减少干扰源、同桌搭配）。
4. **作业调整**：分量（少而精）、呈现（大字、分块）、反馈频率（及时短反馈）。
5. **家校沟通稿**：描述行为 + 说明已做的支持 + 请求配合的具体动作，**不贴标签、不暗示诊断**（不说"像多动症"）。

## 输出规范

- 观察记录表（空表 + 填写示例）；
- 课堂支持计划（一页纸：目标 / 调整项 / 负责人 / 复查时间）；
- 家校沟通稿（300 字以内，可直接用）。

## 边界（硬性）

- **学生支持不代替专业诊断**；不说"你孩子是 ADHD"这类话。
- 如家长已有专业评估，以评估结论为准，skill 只做教育配合。
- 观察记录注意隐私，不在公开场合讨论。
- **结果由教师核对后使用**；持续无改善建议转介校心理老师/专业机构。
