# 新转学生支持

转学生最难的不是跟上课，是"成为这个班的人"。支持分两条线：课程衔接 + 班级融入，按首周、首月排节奏。

## 何时触发

老师说"班里来了个转学生""新生适应方案"时触发。

## 输入清单

1. 转入年级、原学校版本/进度情况；
2. 已知的课程差异点（老师/家长提供）；
3. 首周观察（情绪、交友、课堂状态）。

## 工作流程

1. **课程衔接梳理**：对照本班进度列差异清单，分"已学过/没学过/学得不一样"三类，没学过的排补学顺序（先补工具性知识）。
2. **班级融入安排**：
   - 座位：前排中间，配热心同桌（提前跟同桌沟通角色）；
   - 角色：第一周就给一个具体小职务/小组角色，有事做才有归属感；
   - 介绍：让本人决定介绍方式，不强行上台。
3. **首周支持表**：Day1–Day5 每天 1 个动作（如 Day1 熟悉校园、Day3 第一次小组任务）。
4. **首月节奏表**：Week1 适应 → Week2 融入 → Week3–4 跟进学业，每周 1 次 5 分钟谈话。

## 输出规范

- 课程差异清单表；
- 首周/首月支持节奏表：时间 / 动作 / 负责人 / 观察点；
- 同桌沟通话术（100 字）。

## 边界

- **保护隐私**：不公开转学原因，不给"新生"贴标签起外号；
- 多给正向融入机会，少给"考察期"压力；
- **结果由教师核对后使用**。
