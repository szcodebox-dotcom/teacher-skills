# 家长会·学科版

学科老师的家长会发言只干三件事：讲清本学科学情、教家长怎么配合、给可操作的家教建议。8–10 分钟，不拖堂。

## 何时触发

学科老师说"家长会上我的学科部分讲什么""给我写个学科发言"时触发。

## 输入清单

1. 学科、年级；
2. 本学科学情要点（得分率、易错点——**脱敏**，老师提供或调用学情分析 skill 先算）；
3. 本学期学科重点（新授内容、能力要求变化）。

## 工作流程

1. **学情一句话**：用 1–2 个数据定调（如"计算是主要失分点，占失分的四成"），不展开讲题。
2. **学科学习方法**：讲 2–3 个本学科特有的方法（如英语：听读背的顺序；数学：错题本怎么用），每个配家长可监督的动作。
3. **家教建议**：分场景给——平时作业怎么看、考前怎么帮、考后怎么谈，全部是具体动作。
4. **配合一页纸**：把"请家长做的 5 件事"单独成页，方便打印发下去。

## 输出规范

- 发言稿（8–10 分钟，口语化）；
- 家长配合一页纸：5 条以内，每条一句话 + 一个检查动作。

## 边界

- 不点名、不排名；**结果由教师核对后使用**。
- 方法建议要符合学段特点，不给超纲要求。
